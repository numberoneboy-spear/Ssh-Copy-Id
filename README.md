## 📖 Overview
<a id="overview"></a>

**SSH Copy ID** is an efficient command-line utility for Windows users designed to streamline the process of copying SSH public keys to remote servers. This tool mirrors the Linux `ssh-copy-id` command, making it essential for anyone needing simplified SSH key management. With the **latest version**, users can enjoy a complete software package that includes all features for secure access management.

This utility supports custom SSH key files and ports and automatically creates the necessary `.ssh` directory and `authorized_keys` file on the remote server. The **latest version** enhances security with duplicate key detection and prevention, ensuring existing keys are not overwritten. SSH Copy ID’s cross-platform compatibility further boosts its usability across various environments, making it a practical solution for efficient SSH key management.
